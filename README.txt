QUICKBITE — POLISHED FOOD ORDERING DEMO

QuickBite is a responsive single-page food ordering website redesigned with a clean food-marketplace style inspired by the supplied Platina reference.

Files:
- index.html — main website
- style.css — responsive premium styling
- script.js — search, categories, cart, checkout and order confirmation

Run:
1. Keep all four files in the same folder.
2. Open index.html in Chrome/Edge, or use VS Code Live Server.

No backend is required for this demo. Cart and checkout run in the browser.
